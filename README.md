# Taqi secret website

Single-page static site. Edit **`index.html`** for all copy and styling (everything is in one file).

## Preview locally

Open `index.html` in a browser, or:

```bash
npx --yes serve .
```

## Deploy to Vercel (same account as engagement-keepsake)

From this folder, after `npx vercel login` once:

```bash
npx vercel --prod
```

Or connect the GitHub repo in the [Vercel dashboard](https://vercel.com/new) — no build settings needed.
